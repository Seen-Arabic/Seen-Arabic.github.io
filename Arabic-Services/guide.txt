# دليل خدمات اللغة العربية

هذا الدليل يشرح أدوات موقع [خدمات اللغة العربية](https://seen-arabic.github.io/Arabic-Services/)، ويشير إلى واجهة مكتبة JavaScript التي توفر بعض العمليات نفسها. الموقع التفاعلي والمكتبة البرمجية وواجهة API مشاريع منفصلة؛ تغيير الموقع لا يغيّر المكتبة أو API.

## أدوات الموقع

يحتوي هذا الدليل على أمثلة ثابتة لخمسة تحويلات حتمية. أما التشفير البصري واختيار الحروف البديلة فيه فيعتمدان على اختيارات عشوائية، لذلك قد يختلف الناتج بين مرات التشغيل.

| الأداة                         | دالة المكتبة                        | السلوك                                                                                                                  |
| ------------------------------ | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| الرسم العربي القديم            | `toOldArabic(text, options?)`       | يزيل التشكيل ويبدل الحروف المدعومة برسم بلا نقاط؛ يمكن ضبط استبدال النون والياء المتوسطتين بالباء عبر الخيارات.         |
| التشفير البصري                 | `tashfeer(text, level?)`            | يستبدل بعض الحروف العربية بحروف متشابهة بصريًا. هذا ترميز بصري وليس تشفيرًا أمنيًا ولا يحمي سرية النص.                  |
| التشفير البصري للكلمات المحددة | `tashfeerBannedWords(text, level?)` | يطبق الاستبدال على الكلمات التي تصنفها الدالة مطابقة لقائمة داخل المكتبة؛ ليست أداة إشراف أو ضمانًا لاكتشاف كل الكلمات. |
| إزالة التشكيل                  | `removeTashkeel(text)`              | تحذف علامات التشكيل وتسوّي ألف الوصل.                                                                                   |
| الكلمة إلى حروفها المنطوقة     | `wordToLetters(text)`               | تستبدل الحروف العربية المدعومة بأسمائها المنطوقة وتفصلها بمسافات.                                                       |
| إزالة اللواحق العربية          | `removeArabicAffixes(text)`         | تحذف بادئات أو لواحق من قوائم محددة. هذه قاعدة تقريبية وليست تحليلًا صرفيًا.                                            |
| إزالة التطويل                  | `removeTatweel(text)`               | تحذف علامة التطويل `ـ`.                                                                                                 |

قد تحافظ بعض الدوال على المسافات أو الأحرف غير المدعومة؛ لا تفترض تطبيعًا شاملًا لكل النص.

## أمثلة ثابتة

هذه أمثلة للدوال الحتمية أعلاه:

| الدالة                | الإدخال                                      | الناتج                        |
| --------------------- | -------------------------------------------- | ----------------------------- |
| `toOldArabic`         | `الخَيْلُ وَاللّيْلُ وَالبَيْداءُ تَعرِفُني` | `الحىل واللىل والٮىدا ٮعرڡٮى` |
| `removeTashkeel`      | `الخَيْلُ وَاللّيْلُ`                        | `الخيل والليل`                |
| `wordToLetters`       | `شجرة`                                       | `شين جيم راء تاء_مربوطة`      |
| `removeArabicAffixes` | `المدرسة`                                    | `مدرس`                        |
| `removeTatweel`       | `كن جميـــلا ترى الوجــود جميـــــلا`        | `كن جميلا ترى الوجود جميلا`   |

## استخدام المكتبة

موقع Angular يستخدم الإصدار 1.1.1 من الحزمة ويشغّل التحويلات في المتصفح. لمشروع JavaScript مستقل، ثبّت الحزمة `arabic-services` من npm واتبع [README المكتبة](https://github.com/Seen-Arabic/Arabic-Services-JavaScript#readme) و[توثيقها التقني](https://github.com/Seen-Arabic/Arabic-Services-JavaScript/blob/main/docs/README.md). لا تتطلب زيارة الموقع تثبيت الحزمة.
